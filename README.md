# 行测复盘一体版（xingce-review-pro）

公务员考试行测（行政职业能力测验）讲题、复盘与错因诊断技能，覆盖六大模块：言语理解、逻辑填空、资料分析、数量关系、判断推理、常识判断。

## 它能做什么

- **行测解答**：输入题目（文字 / 截图 / PDF），给出题型识别、解题过程、答案来源
- **行测复盘**：引导你先说自己的思路和当时怎么排除的，再逐题讲解，定位错因
- **错因诊断**：区分"想太多 / 偷换 / 策略问题"等错因，生成错因卡
- **考我 / 复习**：从题库出题测你，管理掌握程度
- **错题复测 / 学情报告**：生成你的弱点档案和学情总结
- **导入题库**：整卷提取 / OCR / 切题 / 答案核验，结构化成题库
- **资料分析速算**：每个计算前置"速算判定"（可快速定位 / 需精算 / 数据不足），只教考场能用的方法

## 三步上手

1. **导入技能**：下载最新 release 的 zip → 在 Agent 平台导入本技能
   （Coze 导入"我的技能"，WorkBuddy 放入 skills 目录）
2. **发一道题**：直接文字发题，或说"帮我解这题"，或粘贴题目截图 / PDF
3. **进阶复盘**：说"复盘"，它会先问你怎么选的，再讲解，全程帮你沉淀错题本和弱点档案

## 常用口令

| 口令 | 作用 |
|---|---|
| 行测解答 / 怎么解 | 直接解题讲方法 |
| 行测复盘 | 先考你思路再讲解 |
| 我选 A/B/C/D | 判定并对比你的答案 |
| 考我 / 复习 | 从题库随机出题 |
| 错因卡 / 错因诊断 | 定位错误原因 |
| 学情报告 / 导出错题报告 | 生成学习档案与导出 |
| 导入题库 | 整卷录入结构化题库 |

## 六大模块方法论库

内置 240+ 张解题方法卡 + 词义辨析库 + 各题型协议，覆盖：

- 言语理解：主旨 / 意图 / 细节 / 排序 / 填句等
- 资料分析：速算、基期现期、增长量、比重、平均数、倍数、混合增速等
- 数量关系：工程、行程、概率、排列组合、几何、容斥、经济利润等
- 判断推理：削弱加强、三段论、真假话、类比、图形推理等
- 常识判断：法律、政治、经济、科技、历史人文、时政、公文等

## 数据隐私

- 技能包只含方法库与协议模板，**不存放任何用户错题、题库、弱点和学习记录**
- 你的学习状态（错因卡 / 弱点档案 / 学情）写入你运行 Agent 的工作目录，随你走、不随包分发
- 错题写回统一走 `scripts/writeback.py`，失败可自动降级为手工记录，可溯源
